本次更新精简安装兼容分支，并统一 MacFanPro 的文档与发布入口。基于 ThermalForge 0.2.3。

## 更新内容

### 改进

- 精简安装流程，移除已停用产品的迁移参数、识别分支及 Homebrew 旧包名映射。
- 统一应用、命令、文档和安装渠道的 MacFanPro 标识。
- 清理旧版专属文档与发行入口；Releases 和 Tags 仅保留 MacFanPro 版本。

本次改动未调整温控算法、传感器采集、原生菜单交互或日志保留逻辑。

## 下载与安装

要求 **Apple Silicon Mac、macOS 14 或更高版本**。

| 文件 | 用途 |
| --- | --- |
| [MacFanPro-0.2.3.15-macos-arm64.tar.gz](https://github.com/macfanpro/macfanpro/releases/download/v0.2.3.15/MacFanPro-0.2.3.15-macos-arm64.tar.gz) | 完整应用与 CLI，解压后安装，无需 Xcode |
| [SHA256SUMS](https://github.com/macfanpro/macfanpro/releases/download/v0.2.3.15/SHA256SUMS) | 下载完整性校验 |

选择一种安装方式：[Homebrew](https://github.com/macfanpro/macfanpro#方式一通过-homebrew-安装) · [下载发行包](https://github.com/macfanpro/macfanpro#方式二下载发行包安装) · [源码构建](https://github.com/macfanpro/macfanpro#方式三从源码构建安装)。Homebrew 当前在本机编译，需要 Xcode 16 或更高版本。GitHub 的 `Source code` 附件是源码，不是完整应用。

## 升级说明

更新前先退出菜单栏应用，再安装新版本并重新打开。Homebrew 更新后仍需同步后台服务和应用，不能只执行 `brew upgrade`。

<details>
<summary>Homebrew 更新命令</summary>

```bash
brew update
brew upgrade macfanpro
macfanpro auto --stop-app
sudo "$(brew --prefix macfanpro)/bin/macfanpro" install
open /Applications/MacFanPro.app
```

</details>

发行包和源码安装用户请参阅 [更新步骤](https://github.com/macfanpro/macfanpro#更新)。

## 验证与限制

- Debug、Release 各 102 项测试及各 108 次客户端断连检查通过；语言资源、发行包 SHA-256 与应用严格签名检查通过。
- 已在 M4 Max MacBook Pro、macOS 27.0 上验证下载产物与 Homebrew 安装，以及三种语言、两种温度单位、菜单连续刷新和实际风扇控制。
- 首次更新时发现旧应用在后台切换期间短暂断连；改用先退出应用再同步的步骤后，两次完整安装与运行检查均未新增 ERROR 或崩溃报告。
- 发行包使用 ad-hoc 签名，尚未经过 Apple 公证。未覆盖其他机型、所有系统版本及本次睡眠唤醒验证。
