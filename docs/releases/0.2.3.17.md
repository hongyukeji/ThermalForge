本次更新降低运行日志的写入开销，并让 `--purge-data` 卸载时一并清理后台服务日志。基于 ThermalForge 0.2.3。

## 更新内容

### 改进

- 运行日志写入不再逐行扫描日志目录。后台写一行的开销从 0.7–1.1 毫秒降到约 57 微秒，且不再随日志文件增多而变慢；后台服务在风扇调速时每秒最多写约 22 行。日志的单文件、总量与保留天数上限不变。
- README 补充后台服务日志的查看方法、运行日志的清理时机，以及旧版本遗留采样目录不会自动删除的原因。

### 修复

- `sudo macfanpro uninstall --purge-data` 现在会一并删除后台服务日志目录 `/var/root/Library/Logs/MacFanPro/`，此前卸载后会残留。不带 `--purge-data` 的卸载仍保留日志。

温控算法、传感器读取、界面与风扇控制未改变。

## 下载与安装

要求 **Apple Silicon Mac、macOS 14 或更高版本**。

| 文件 | 用途 |
| --- | --- |
| [MacFanPro-0.2.3.17-macos-arm64.tar.gz](https://github.com/macfanpro/macfanpro/releases/download/v0.2.3.17/MacFanPro-0.2.3.17-macos-arm64.tar.gz) | 完整应用与 CLI，解压后安装，无需 Xcode |
| [SHA256SUMS](https://github.com/macfanpro/macfanpro/releases/download/v0.2.3.17/SHA256SUMS) | 下载完整性校验 |

选择一种安装方式：[Homebrew](https://github.com/macfanpro/macfanpro#方式一通过-homebrew-安装) · [下载发行包](https://github.com/macfanpro/macfanpro#方式二下载发行包安装) · [源码构建](https://github.com/macfanpro/macfanpro#方式三从源码构建安装)。Homebrew 7 需要先执行一次 `brew trust macfanpro/tap`。
