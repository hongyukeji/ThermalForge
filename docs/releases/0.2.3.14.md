首个以 MacFanPro 名称发行的版本，为 Apple Silicon Mac 提供菜单栏应用、命令行工具和后台服务。基于 ThermalForge 0.2.3。

## 更新内容

### 应用与发行

- 使用独立的 `macfanpro` 命令、应用标识、后台服务、配置和日志目录。
- 通过 `macfanpro/macfanpro` 发布源码与发行包，通过 `macfanpro/tap` 分发 Homebrew 配方。
- README 展示本机安装后的真实应用截图。

### 界面与语言

- 保留原生菜单栏、自动弹窗高度、居中的温度标签，以及退出按钮上方的分隔线。
- 提供英语、简体中文、繁体中文界面，支持语言切换和摄氏/华氏显示。

## 下载与安装

要求 **Apple Silicon Mac、macOS 14 或更高版本**。

| 文件 | 用途 |
| --- | --- |
| [MacFanPro-0.2.3.14-macos-arm64.tar.gz](https://github.com/macfanpro/macfanpro/releases/download/v0.2.3.14/MacFanPro-0.2.3.14-macos-arm64.tar.gz) | 本版本完整应用与 CLI，解压后安装，无需 Xcode |
| [SHA256SUMS](https://github.com/macfanpro/macfanpro/releases/download/v0.2.3.14/SHA256SUMS) | 下载完整性校验 |

需要安装此历史版本时，请使用上面的发行包；[Homebrew 安装](https://github.com/macfanpro/macfanpro#方式一通过-homebrew-安装)会安装配方当前提供的稳定版，不锁定到 0.2.3.14。三种安装方式的完整说明见 [README](https://github.com/macfanpro/macfanpro#安装)。

## 升级说明

更新现有安装前，先退出正在运行的应用，再同步新版本的应用与后台服务，详见 [更新步骤](https://github.com/macfanpro/macfanpro#更新)。后续版本请查看 [最新发行](https://github.com/macfanpro/macfanpro/releases/latest)。

## 验证与限制

- Debug、Release 各 103 项测试及各 108 次客户端断连检查通过；已核对下载产物的 SHA-256 和应用严格签名。
- 已在 M4 Max MacBook Pro、macOS 27.0 上验证候选版、下载产物及 Homebrew 安装，包含语言、单位、菜单刷新、退出与实际风扇控制。
- 发行包使用 ad-hoc 签名，尚未经过 Apple 公证；该记录不代表其他机型、所有 macOS 版本或睡眠唤醒均已验证。
