本次更新调整菜单底部布局：语言与新增的版本号组成独立区块，放在“退出”上方。基于 ThermalForge 0.2.3。

## 更新内容

### 改进

- 语言选择与新增的“版本”一行组成独立区块，上下各有一条分隔线，位于“退出”正上方。版本号即当前应用版本，随每次发行自动更新。
- “°F / °C”与“登录时启动”保持在原位置，与上游一致。

温控算法、传感器读取、日志与风扇控制未改变。

## 下载与安装

要求 **Apple Silicon Mac、macOS 14 或更高版本**。

| 文件 | 用途 |
| --- | --- |
| [MacFanPro-0.2.3.18-macos-arm64.tar.gz](https://github.com/macfanpro/macfanpro/releases/download/v0.2.3.18/MacFanPro-0.2.3.18-macos-arm64.tar.gz) | 完整应用与 CLI，解压后安装，无需 Xcode |
| [SHA256SUMS](https://github.com/macfanpro/macfanpro/releases/download/v0.2.3.18/SHA256SUMS) | 下载完整性校验 |

选择一种安装方式：[Homebrew](https://github.com/macfanpro/macfanpro#方式一通过-homebrew-安装) · [下载发行包](https://github.com/macfanpro/macfanpro#方式二下载发行包安装) · [源码构建](https://github.com/macfanpro/macfanpro#方式三从源码构建安装)。Homebrew 7 需要先执行一次 `brew trust macfanpro/tap`。

## 升级说明

更新前先退出菜单栏应用，再安装新版本并重新打开；Homebrew 更新后还需同步后台服务和应用，详见 [更新步骤](https://github.com/macfanpro/macfanpro#更新)。
