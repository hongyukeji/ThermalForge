本次更新修正 M4 上 CPU 温度的取值：GPU 负载下不再把芯片热点温度显示为 CPU 温度。基于 ThermalForge 0.2.3。

## 更新内容

### 修复

- CPU 温度只取 CPU 核心传感器。此前在 M4 上会混入芯片热点和非核心传感器，GPU 满载时 CPU 显示 73–75°C，而实际核心只有 60–63°C；现在与 Stats 的"最热 CPU"相差不超过 0.5°C。
- 菜单栏温度改为 CPU、GPU 两行中的较高值，与面板显示一致。
- M4 Max 上被误认为 GPU 的电池传感器不再参与 GPU 温度；`macfanpro status` 和记录日志中不再出现低于 10°C 的占位读数。

风扇曲线、95°C 安全阈值和界面布局未改变：风扇控制仍跟随芯片最热点。
